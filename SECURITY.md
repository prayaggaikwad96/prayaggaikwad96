# Security Policy

## Scope

This repository contains the GitHub profile README and related profile content. It is not the security reporting channel for vulnerabilities in other projects linked from the profile.

- For a vulnerability in a linked project, report it to that project's maintainers using that project's security policy.
- For a vulnerability in this repository's own content or future automation, use GitHub's **Report a vulnerability** option on this repository's **Security** tab when private vulnerability reporting is available.

Do not publish sensitive vulnerability details, credentials, tokens, private data, or exploit instructions in public issues, pull requests, discussions, or commit messages.

## Supported versions

The default branch, `main`, is the maintained version of this profile repository. Historical commits are retained for reference and are not guaranteed to receive updates.

## If private reporting is unavailable

Contact the repository owner through the GitHub profile and request a private disclosure channel. Do not disclose exploit details publicly while arranging contact.

## Credential exposure

If a credential is exposed, revoke or rotate it immediately. Deleting the file or commit does not invalidate the credential.

## Response expectations

Reports will be reviewed as time and severity permit. No fixed response-time or remediation SLA is promised.
